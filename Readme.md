# Cheerful Givers Community Outreach

## Overview

Cheerful Givers Community Outreach is a responsive website developed for a community organisation based in Bloekombos, Kraaifontein. The website promotes the organisation's mission, services, leadership team, and community initiatives while providing visitors with an easy way to learn more and get involved.

---

## Features

- Responsive single-page website
- Dynamic About and Services content loaded from JSON
- Service search and filtering
- Enquiry modal with form validation
- Interactive Leaflet map
- Responsive layout for desktop, tablet, and mobile
- SEO metadata and descriptive image alt text
- Clean navigation and user-friendly interface

---

## Technologies Used

- HTML5
- CSS3 (Flexbox and Grid)
- JavaScript (ES6)
- JSON
- Leaflet.js
- Git
- GitHub

---

## Responsive Design

The website adapts to different screen sizes to provide a consistent user experience.

- **Desktop:** Multi-column layout
- **Tablet:** Responsive layout with adjusted spacing
- **Mobile:** Single-column stacked layout
